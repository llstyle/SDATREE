Лабораторная работа №5: Бинарные деревья поиска (создание, вставка и обходы)
Цель: Ознакомиться с бинарными деревьями поиска (BST), их созданием, добавлением элементов и базовыми обходами.
Задание:
• Определить структуру узла бинарного дерева (бинарное дерево строиться самостоятельно). Узел должен содержать:
• Поля данных.
• Указатели на левое и правое поддеревья.
• Реализовать функцию вставки нового элемента в дерево с учётом правил BST (левый потомок меньше родителя, правый — больше).
• Реализовать три вида обходов дерева и вывести результат на экран:
• Прямой (preorder, NLR).
• Центрированный (inorder, LNR).
• Обратный (postorder, LRN).
• Обход в глубину (DFS, Depth-First Search) – можно реализовать через рекурсию, используя один из способов обхода (обычно LNR).
• Обход в ширину (BFS, Breadth-First Search) – реализуется через очередь (FIFO).
• Реализовать функцию поиска элемента в дереве по заданному ключу.
