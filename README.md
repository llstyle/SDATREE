Лабораторная работа №6: Расширенные операции с бинарными деревьями
Цель: Добавить в бинарное дерево возможность удаления узлов, балансировки и сохранения данных.
Задание:
• В существующем репозитории создайте новую ветку, для добавления нового функционала. (После того как все изменения будут отлажены и утверждены выполните merge ветки с основным разделом)
• Реализовать функцию удаления узла из бинарного дерева по заданному ключу. Учесть три случая:
• Удаление листа (узла без потомков).
• Удаление узла с одним потомком.
• Удаление узла с двумя потомками (найти замену узлу).
• Реализовать функцию поиска минимального и максимального элемента в дереве.
• Реализовать функцию вычисления высоты дерева.
• Добавить возможность сохранения дерева в файл и его загрузки (формат бинарный или текстовый).
• Реализовать функцию полного удаления дерева с освобождением памяти перед завершением программы.
